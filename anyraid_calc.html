> anyraid_capacity.calc

Simulates AnyRAID's actual tile-allocation algorithm (First-Fit-Descending bin-packing): each stripe picks the nparity + ndata disks with the most free capacity. Unevenly sized disks therefore create unusable space on the larger drives.

How this is calculated: each disk is split into tiles of the chosen tile size (rounded down). In each round, the stripe width disks with the most free tiles are picked and one tile from each is assigned to a new stripe — until there are no longer enough disks with free tiles. This is exactly the First-Fit-Descending procedure implemented in calculate_asize() in vdev_anyraid.c. Tiles on excessively large disks that can never take part in a full stripe are left over as waste — this is precisely the behaviour that distinguishes AnyRAID from classic RAIDZ (where all disks must be the same size, or the excess is lost entirely).
